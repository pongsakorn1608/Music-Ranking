# Music Ranking

เว็บไซต์ตัวอย่างสำหรับจัดอันดับและแนะนำเครื่องดนตรี สร้างด้วย HTML5, CSS3 และ JavaScript พื้นฐาน

## วิธีเปิดเว็บ

เปิดไฟล์ index.html ด้วยเว็บเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code

## หน้าที่มี

- index.html หน้าหลักและตัวกรองงบประมาณ
- category.html แสดงสินค้าตามหมวดหมู่จากพารามิเตอร์ใน URL
- detail.html แสดงข้อมูลสินค้าแต่ละรายการ
- team.html ข้อมูลทีมและช่องทางติดต่อ
- style.css รูปแบบและ Responsive Design ร่วมกัน
- products.js ข้อมูลสินค้าที่ใช้ร่วมกัน

## หมายเหตุ

รูปสินค้าปัจจุบันใช้ URL ภายนอกที่มีอยู่ในโค้ดต้นฉบับ จึงต้องเชื่อมต่ออินเทอร์เน็ตเมื่อเปิดหน้าเว็บ หากต้องการให้เว็บทำงานแบบออฟไลน์ ให้นำรูปที่มีสิทธิ์ใช้งานใส่ในโฟลเดอร์ images แล้วเปลี่ยนค่า src ในไฟล์ HTML และ products.js
